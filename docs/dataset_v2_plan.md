# 温州话ASR数据集建设方案 — 迈向100万条

## 现状

当前系统已在运行，但 ASR 使用 mock 模拟。要实现真实翻译温州话，核心瓶颈是 **缺少温州话语音→普通话文本的平行语料**。

## 多源汇聚路线（目标100万条）

### 📡 源1：网络爬取（10万条）

| 平台 | 内容类型 | 预估量 | 工具 |
|------|---------|--------|------|
| **Bilibili** | 温州话视频+字幕 | 2万 | bilibili-api + whisper subtitle |
| **抖音** | 温州话短视频 | 5万 | douyin scraper |
| **微博** | 温州话文字帖子 | 1万 | weibo API |
| **703804论坛** | 温州本地论坛 | 0.5万 | requests + parser |
| **温州新闻/广播** | 新闻播报 | 1.5万 | 广电节目录音转写 |

### 🎤 源2：众包录制（40万条）

设计一套温州话采集小程序：
- 展示普通话句子 → 用户用温州话录音 → 音频+文本自动配对
- 目标：200位温州话母语者 × 2000条/人
- 场景覆盖：医院/家庭/购物/政务/商务/出行/学校/情感

### ✏️ 源3：App纠错闭环（30万条）

- 用户上传温州话音频 → ASR识别（可能不准）
- 用户修正→保存修正后文本→**自动成为训练数据**
- 当前修正存储模块已就绪，只差流量

### 🤖 源4：半监督/增强（20万条）

- 已有人工标注数据 → 训练 weak labeler → 自动标注未标注音频
- 数据增强：加噪/变速/混响/音量抖动
- 跨方言迁移：闽南语/粤语ASR模型迁移知识

## 技术路线图

```
阶段1（2周）：完成B站+抖音爬虫搭建 → 自动提取温州话片段+字幕
    输出：1万条弱标注平行语料
    里程碑：faster-whisper + fine-tune → CER从30%降至20%

阶段2（1个月）：众包录制小程序 + 人工纠错推广
    输出：10万条人工标注语料
    里程碑：FunASR fine-tune → CER降至10%

阶段3（3个月）：规模化采集 + 半监督标注
    输出：30万条
    里程碑：多模型融合 → CER降至5%

阶段4（6个月）：100万条里程碑
    里程碑：端到端温州话ASR模型，CER < 3%（即准确率>97%）
```
