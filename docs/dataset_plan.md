# 温州话数据采集与标注计划

## 1. 数据格式

每条样本包括：

- audio_id
- audio_path
- mandarin_corrected
- speaker_id
- gender
- age
- scene
- noise_level
- note

## 2. 音频要求

- wav
- 16 kHz
- mono
- 3–15 秒为主
- 每条一句话或一个完整意图
- 避免多人重叠

## 3. 场景分类

- 医院问诊
- 挂号/缴费
- 家庭日常
- 买菜/购物
- 出行问路
- 商务沟通
- 政务办事
- 情绪表达

## 4. 标注规则

- 不标温州话文本
- 直接标普通话标准文本
- 不添加说话人没有表达的信息
- 可补全自然标点
- 保留专有名词

## 5. 质量控制

- 每 100 条抽检 20 条
- 双人复核高频错误
- 统计 CER、人工可理解度
- 建立常见错词表
