# 产品设计：温州话原位转普通话 Agent

## 1. 用户场景

### 医院
老人用温州话描述症状，系统输出普通话文字给医生查看。

### 政务窗口
群众使用方言表达办事需求，系统转为普通话，降低沟通成本。

### 家庭沟通
长辈说温州话，年轻人或外地亲友获得普通话文本和语音。

### 商务接待
本地客户使用温州话，系统快速转普通话，辅助会议记录。

---

## 2. MVP 功能

- 上传音频
- 录音输入
- ASR 原始结果
- 普通话规范化结果
- 普通话 TTS
- 人工纠错保存
- 批量转写脚本
- CER 评估脚本

---

## 3. 交互原则

- 输出双栏：原始识别 / 普通话结果
- 保留人工纠错入口
- 不隐藏模型不确定性
- 对低置信度结果提示用户复核
- 对私人语音数据提示本地处理和授权
