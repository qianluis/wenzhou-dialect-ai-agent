## 准确率基线(edge-tts 合成普通话回灌 ASR)

| 输入(原文) | 识别(raw) | CER |
|------|------|------|
| 今天天气很好,我们一起去吃饭吧。 | 今天天气很好,我们一起去吃饭吧。 | **0.00%** |
| 请问现在几点了,医生让我明天再来。 | 请问现在几点了,一声让我明天再来。 | 11.76% |
| 今天去医院,医生让我明天再来。 | 今天去医院,医生让我明天再来。 | **0.00%** |

> 注:CER 误差主要来自 base 模型对个别词的误听(医生→一声),非链路问题。换 `small` 或 GPU 栈可进一步降低。

## 规范化(方言→普通话,仅在检测到方言标记时触发)

| 输入 | 输出 |
|------|------|
| 该日去医院,医生话我明朝再来 | 今天去医院,医生话我明天再来。 |
| 你晓得渠勒阿垡不 | 你知道他/她在哪里不。 |

> 纯普通话文本**原样放行**(不再误把 好→可以、饭→米饭),解决了首版的过度替换问题。

## 与 GPU 版(CLAUDE.md 原设计)的差异

本机把 4 个 GPU 服务合并为单进程、引擎换 CPU/网络实现,接口字段不变。迁回 GPU ECS 时:
- ASR 换回 Qwen3-ASR docker(`:8001`),改 `server/asr.py`;
- 规范化换回 vLLM Qwen3-1.7B(`:8002`),设 `NORM_BACKEND=openai` 指向其 OpenAI 兼容端点;
- TTS 换回 CosyVoice2(`:8003`),改 `server/tts.py`。
前端与 `/ws/asr`、`/tts` 协议无需改动。
